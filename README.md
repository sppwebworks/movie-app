# 🎬 MovieApp

A responsive movie discovery app built with React, Redux Toolkit, and Context API.

## ✨ Features
- Trending movies (TMDB API)
- Debounced search with history
- Favorites (Redux + localStorage)
- Movie details page
- Dark/Light theme (Context API)
- Toast notifications
- Loading skeletons + error boundary
- Lazy-loaded routes
- Fully responsive

## 🛠 Tech Stack
React 18 · Redux Toolkit · Context API · React Router · Axios · Vite · CSS3

## 🚀 Setup
```bash
git clone <repo>
cd movie-app
npm install
# create .env with VITE_TMDB_API_KEY=...
npm run dev
